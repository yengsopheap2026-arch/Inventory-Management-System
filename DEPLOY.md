# Inventory Management System — Deployment Guide

## 📋 Project Overview

A single-page HTML application for managing inventory. Built with vanilla HTML/CSS/JavaScript.

## 🚀 Quick Start

### Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/yengsopheap2026-arch/Inventory-Management-System.git
   cd Inventory-Management-System
   ```
2. Open `Stockflow — Inventory Management.html` in any modern browser (Chrome, Firefox, Edge, Safari).

### No build tools required — it's a standalone HTML file!

## 🌐 Deployment Options

### Option 1: GitHub Pages (Free, Recommended)
1. Go to the repository on GitHub: [https://github.com/yengsopheap2026-arch/Inventory-Management-System](https://github.com/yengsopheap2026-arch/Inventory-Management-System)
2. Navigate to **Settings → Pages**
3. Under **Source**, select `main` branch and `/ (root)`
4. Click **Save**
5. Your app will be live at: `https://yengsopheap2026-arch.github.io/Inventory-Management-System/`

### Option 2: Direct File Sharing
- Simply share the `Stockflow — Inventory Management.html` file with anyone.
- They open it in a browser — no server needed.

### Option 3: Any Static Host
- Upload the HTML file to any static hosting service (Netlify, Vercel, Surge, Firebase Hosting).
- Drag and drop the file or connect the Git repo directly.

## 📝 Notes

- The main application file uses an **em-dash** (—) in its name — be careful when typing it.
- This is a client-side application — no backend server or database required.
- All data is stored locally in the browser (localStorage or similar).
