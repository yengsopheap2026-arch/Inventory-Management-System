# 📦 Stockflow — Inventory Management System

A simple, lightweight inventory management application built with HTML, CSS, and JavaScript — no dependencies, no build tools required.

## ✨ Features

- 📊 **Track Inventory** — Add, edit, and remove items with ease
- 🔍 **Search & Filter** — Quickly find what you're looking for
- 📈 **Stock Levels** — Monitor quantities and get notified about low stock
- 📝 **Category Management** — Organize items by category
- 💾 **Local Storage** — Data persists in the browser automatically
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile
- ⚡ **Zero Dependencies** — Just open the HTML file — nothing to install!

## 🖥️ How to Use

1. **Add Item**: Click the "Add Item" button and fill in the details (name, category, quantity, price)
2. **Edit Item**: Click the edit icon next to any item to modify its details
3. **Delete Item**: Click the delete icon to remove an item from the inventory
4. **Search**: Use the search bar to filter items by name or category
5. **Track Stock**: Low stock items are highlighted so you can restock quickly
